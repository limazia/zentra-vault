# Zentra Vault

O Zentra Vault é um aplicativo de cofre seguro e fácil de usar, desenvolvido com Nest.js e React. Ele oferece uma interface simples para que os usuários armazenem e gerenciem suas informações confidenciais, como senhas, notas e outros dados sensíveis.
